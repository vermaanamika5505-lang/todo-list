# ✨ Smart To-Do List

A clean and responsive To-Do List web application built using
HTML, CSS and JavaScript.

## 🌐 Live Demo

[View Live Website] https://effortless-swan-3a6adc.netlify.app

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- All / Pending / Completed filters
- Task categories
- Date and time support
- Task sorting
- Progress tracking
- Dark mode
- Local storage
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Local Storage
